# Security Policy

## Supported versions

`manotz` is pre-1.0. Security fixes are applied on the default branch (`master`) only.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email **emad.m.baqeri@gmail.com** with:

- A description of the issue
- Steps to reproduce (PoC if possible)
- Impact assessment if you have one

You should receive an acknowledgement within a few days. Once a fix is available, we will credit you in the advisory unless you prefer to remain anonymous.
